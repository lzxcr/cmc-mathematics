# 题目

设空间中定点 $P$ 到一定直线 $l$ 的距离为 $p$。一族球面中的每个球面都过点 $P$，且截直线 $l$ 得到的弦长都是定值 $a$。求该球面族的球心的轨迹。

# 解答

取 $l$ 为 $z$ 轴，原点为 $P$ 在 $l$ 上的垂足，并选 $x$ 轴使 $P=(p,0,0)$；当 $p=0$ 时任取一个垂直于 $l$ 的 $x$ 轴。

设球心为 $Q=(x,y,z)$，半径为 $R=|Q-P|$，球心到 $l$ 的距离为 $d$。弦长条件等价于 $R^2-d^2=a^2/4$，而
\[
R^2-d^2=(x-p)^2+y^2+z^2-(x^2+y^2)
=z^2-2px+p^2.
\]
因此球心轨迹的方程为
\[
\boxed{z^2-2px+p^2=\frac{a^2}{4}}.
\]
反之，满足此式的点给出 $R^2=d^2+a^2/4$；当 $a>0$ 时半径为正，且球面在 $l$ 上截得的弦长恰为 $a$，故没有遗漏或多出的点。

当 $p>0$ 时，轨迹是母线平行于 $y$ 轴的抛物柱面；当 $p=0$、$a>0$ 时，它退化为两个平行平面 $z=\pm a/2$。

# 评注

柱面结构来自平方差中的 $y^2$ 抵消：沿 $y$ 方向移动球心时，半径与球心到直线的距离一般都会改变，但 $R^2-d^2$ 保持不变。

通常弦长取 $a>0$。若另把切点视为长度为零的弦，上述方程仍适用；在 $p=a=0$ 时须从平面 $z=0$ 中删去原点，因为该点对应半径为零，并非球面。轨迹的几何分类应区分 $p>0$ 与 $p=0$；后一种情形已由同一方程自然包含。
