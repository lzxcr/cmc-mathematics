# 题目

将平面抛物线 $\Gamma$ 绕其准线旋转一周，得到曲面 $S$。求 $S$ 的两个主曲率之比。

# 解答

取准线为 $z$ 轴，则母线可写为 $\rho(z)=a+z^2/(4a)$，其中 $a>0$。旋转曲面的参数式为
\[
X(z,\theta)=(\rho(z)\cos\theta,\rho(z)\sin\theta,z).
\]
子午线与纬线方向互相正交，且两基本形式的混合项均为零，所以它们就是主方向。取向外法向后，两主曲率为
\[
k_{\mathrm{mer}}=\frac{\rho''}{(1+\rho'^2)^{3/2}},\qquad
k_{\mathrm{par}}=-\frac1{\rho\sqrt{1+\rho'^2}}.
\]
由于 $\rho''=1/(2a)$、$\rho=a(1+\rho'^2)$，得到
\[
\frac{k_{\mathrm{mer}}}{k_{\mathrm{par}}}=-\frac12.
\]
交换两主曲率的次序时比值为 $-2$。

# 评注

该旋转面处处具有负 Gauss 曲率。比值不受法向选择影响，因为改变法向会使两个主曲率同时变号；主曲率的排序则须明确。
