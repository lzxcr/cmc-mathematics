# 题目

（微分几何）已知椭圆柱面 $S$：
\[
r(u, v) = \{a \cos u, b \sin u, v\}, \quad -\pi \leq u \leq \pi, \quad -\infty < v < +\infty.
\]

（1）求 $S$ 上任意测地线的方程；

（2）设 $a = b$。取 $P = (a,0,0)$，$Q = (a\cos u_0, a\sin u_0, v_0)$，其中 $-\pi < u_0 < \pi$，$-\infty < v_0 < +\infty$。写出 $S$ 上连接 $P,Q$ 两点的最短曲线的方程。

# 解答

（1）令
\[
s(u)=\int_0^u\sqrt{a^2\sin^2t+b^2\cos^2t}\,\mathrm dt.
\]
这是横截椭圆的有向弧长；它吸收了原参数 $u$ 方向的速度，使柱面的度量变为 $\mathrm ds^2+\mathrm dv^2$。因此在展开平面中测地线就是直线。全部仿射参数测地线可写为
\[
s(u(t))=\alpha t+\beta,\qquad v(t)=\gamma t+\delta,
\quad (\alpha,\gamma)\ne(0,0).
\]
这里允许 $u$ 在实数上连续延拓，因而也包括绕柱多圈的测地线。

（2）圆柱的展开坐标为 $(au,v)$。从 $P$ 出发的曲线，其终点的提升为 $(a(u_0+2\pi k),v_0)$，$k\in\mathbb Z$。固定 $k$ 时直线段最短，其长度为 $\sqrt{a^2(u_0+2\pi k)^2+v_0^2}$。由 $|u_0|<\pi$，最小值对应 $k=0$，所以最短曲线为
\[
\gamma(t)=(a\cos(tu_0),a\sin(tu_0),tv_0),\qquad0\leq t\leq1.
\]
该式同时包含母线段、圆弧及螺旋线段的情形。

# 评注

局部展开把测地线问题化为直线问题，但两点间最短性还要比较不同绕数的终点提升。若允许 $|u_0|=\pi$，会出现两个等长的最短螺旋线段；题设排除了这个非唯一情形。见[方法卷：测地线与变分](#app:geometry-variation)。
