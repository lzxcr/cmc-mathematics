# 题目

（实变函数）设 $E \subset \mathbb{R}^n$ 为可测集，满足 $m(E) < \infty$。设 $f, f_k \in L^2(E)$，在 $E$ 上几乎处处有 $f_k \rightarrow f$，且
\[
\limsup_{k \rightarrow \infty} \int_E \left|f_k(t)\right|^2 \mathrm{d}t \leq \int_E |f(t)|^2 \mathrm{d}t < \infty.
\]
求证：
\[
\lim_{k \rightarrow \infty} \int_E \left|f_k(t) - f(t)\right|^2 \mathrm{d}t = 0.
\]

# 解答

题设只给出范数的上界，不能直接对 $|f_k-f|^2$ 使用控制收敛。改用平行四边形恒等式，把差的范数化成已知的上界减去一个可由 Fatou 控制的下界。因 $f_k+f\to2f$ 几乎处处，
\[
4\|f\|_2^2\leq\liminf_k\|f_k+f\|_2^2.
\]
因此
\[
\limsup_k\|f_k-f\|_2^2
=\limsup_k\bigl(2\|f_k\|_2^2+2\|f\|_2^2-\|f_k+f\|_2^2\bigr)
\leq0.
\]
所求结论成立。这里完全不需要底空间测度有限。

# 评注

集中尖峰解释了范数条件的必要性：$f_k=\sqrt{k}\,\mathbf1_{(0,1/k)}$ 几乎处处趋于零，但范数始终为 $1$。本题条件排除了这种残留能量；与 Hilbert 空间中“弱收敛加范数收敛推出强收敛”的联系见[方法卷：Hilbert 空间的收敛](#app:integration-hilbert)。
