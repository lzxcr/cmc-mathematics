# 题目

在空间直角坐标系下，设有椭球面
\[
S: \frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1, \quad a, b, c > 0
\]
及 $S$ 外部一点 $A(x_0, y_0, z_0)$，过 $A$ 点且与 $S$ 相切的所有直线构成锥面 $\Sigma$。证明：存在平面 $\Pi$，使得交线 $S \cap \Sigma = S \cap \Pi$；同时求出平面 $\Pi$ 的方程。

# 解答

把椭球写成 $X^TQX=1$，其中 $Q=\operatorname{diag}(a^{-2},b^{-2},c^{-2})$，外点记为 $X_0$。在点 $X$ 的切平面是 $X^TQY=1$，它包含 $X_0$ 当且仅当
\[
X_0^TQX=1.
\]
因此切点轨迹恰为椭球与平面
\[
\Pi:\frac{x_0x}{a^2}+\frac{y_0y}{b^2}+\frac{z_0z}{c^2}=1
\]
的交集。为核实反向包含，若 $X\in S\cap\Pi$，则
\[
[X+t(X_0-X)]^TQ[X+t(X_0-X)]-1
=t^2(X_0-X)^TQ(X_0-X),
\]
故直线 $XX_0$ 在 $X$ 处与椭球相切。

# 评注

平面 $X_0^TQX=1$ 是外点 $X_0$ 的极平面。二次项的极化把“切线在该点二重接触”变成这个一次条件，因此全部切点共面。概念与一般二次曲面的处理见[方法卷：二次曲面与极化](#app:geometry-quadric)。
