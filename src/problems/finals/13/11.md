# 题目

设函数 $f(z)$ 在单位圆内解析，且对一切满足 $0 < \rho < 1$ 的 $\rho$，其实部 $\operatorname{Re} f(z) = u(\rho, \theta) \leq 1, u(0) = 0$。证明：$|a_n| \leq 2(n = 1, 2, \cdots)$，这里 $a_n$ 为 $f(z)$ 的 Taylor 展开式的系数。

# 解答

令 $v(z)=1-\operatorname{Re}f(z)\ge0$，则 $v(0)=1$。在半径 $\rho<1$ 的圆周上展开 $\operatorname{Re}f=(f+\overline f)/2$；正频率只来自 $f/2$。因此对 $n\ge1$，Fourier 正交性给出
\[
-a_n\rho^n=\frac1\pi\int_0^{2\pi}v(\rho e^{i\theta})e^{-in\theta}\,\mathrm d\theta.
\]
由调和函数平均值性质，$\int_0^{2\pi}v(\rho e^{i\theta})\,\mathrm d\theta=2\pi$，故 $|a_n|\rho^n\le2$。令 $\rho\uparrow1$ 即得 $|a_n|\le2$。

# 评注

先把单边实部上界变成非负调和函数，非负性使 Fourier 系数受总质量控制。常数 $2$ 最优，例如 $f(z)=-2z/(1-z)$ 满足 $1-\operatorname{Re}f=\operatorname{Re}(1+z)/(1-z)>0$，全部非零 Taylor 系数的模都是 $2$。圆盘与半平面的转换见[方法卷：圆盘映射](#app:complex-disk)。
