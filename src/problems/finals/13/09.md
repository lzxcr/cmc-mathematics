# 题目

证明：在 $\mathbb{R}$ 上总存在 2 个互不相交的 Borel 集 $A_1$ 和 $A_2$，使得对任意的非空开区间 $J$，成立 $\left|A_k \cap J\right| > 0 (k=1,2)$，其中 $|E|$ 表示集合 $E$ 的 Lebesgue 测度。

# 解答

只需在可数区间基的每个成员内，为两个集合各预留一块正测度集合。枚举所有有理端点非空有界开区间为 $I_1,I_2,\dots$。递归选取两两不交的正测度无处稠密紧集 $K_n^1,K_n^2\subset I_n$：在第 $n$ 步，此前有限个紧集的并仍无处稠密，故 $I_n$ 中有两个与它们不交的小开区间，在其中各放入一个正测度无处稠密紧集即可。这样的紧集可由闭区间删去包含全部有理点的开集得到：使删去区间的总长度小于原区间长度，剩余集便有正测度且没有内点。

令 $A_j=\bigcup_{n\ge1}K_n^j$。它们是互不相交的 $F_\sigma$ 集。任意非空开区间 $J$ 包含某个 $I_n$，于是 $|A_j\cap J|\ge|K_n^j|>0$。
