# 题目

（1）设 $f(z)$ 在 $|z| < 1$ 内解析，且 $|f(z)| < 1$。证明：
\[
(1 - |z|^2)|f'(z)| \leq 1 - |f(z)|^2.
\]
（2）设 $f(z)$ 在 $|z| < 1$ 内解析，$F(z)$ 在 $|z| < 1$ 内单叶解析，且 $f(0) = F(0)$，且满足 $f(|z| < 1) \subseteq F(|z| < 1)$。证明：存在 $|z| < 1$ 内的解析函数 $w(z)$，使得 $f(z) = F(w(z))$，且 $|w(z)| \leq |z|$。
（3）在 （2）的条件下，证明：$|f'(0)| \leq |F'(0)|$，且等号成立当且仅当 $w(z) = \mathrm{e}^{i\theta}z$（其中 $\theta$ 为实数）。

# 解答

（1）Schwarz 引理以原点为基点；用圆盘自同构把考察点及其像同时移到原点，就能得到任意点的导数界。设 $\phi_a(z)=(z-a)/(1-\bar az)$。对固定 $a\in\mathbb D$，函数
\[
F=\phi_{f(a)}\circ f\circ\phi_a^{-1}
\]
映单位圆盘入自身且 $F(0)=0$。Schwarz 引理给出
\[
|F'(0)|=\frac{(1-|a|^2)|f'(a)|}{1-|f(a)|^2}\le1,
\]
即 Schwarz–Pick 不等式。

（2）单叶解析函数的导数不为零，故 $F^{-1}$ 在 $F(\mathbb D)$ 上解析。取 $w=F^{-1}\circ f$，则 $w:\mathbb D\to\mathbb D$、$w(0)=0$，所以 $|w(z)|\le|z|$。

（3）链式法则给出 $f'(0)=F'(0)w'(0)$。Schwarz 引理及其等号条件说明 $|w'(0)|\le1$，等号当且仅当 $w(z)=e^{i\theta}z$。

单叶映射的解析逆、Schwarz 引理和等号刚性见[方法卷：圆盘映射](#app:complex-disk)。
