# 题目

设 $L_0(x) = 1$，$L_1(x) = x$，
$L_{n+1}(x) = \frac{2n+1}{n+1}xL_n(x) - \frac{n}{n+1}L_{n-1}(x)$，$n \geq 1$。
记 $\delta_{mn}$ 为 Kronecker 记号。众所周知，Legendre 多项式 $L_n$ 有以下性质：
(i) $\int_{-1}^{1}L_m(x)L_n(x)\mathrm{d}x = \frac{2}{2n+1}\delta_{mn}\ (\forall m,n \geq 0)$；
(ii) $L_{n-1}'(x) = xL_n'(x) - nL_n(x)$；
(iii) $L_{n+1}'(x) = xL_n'(x) + (n+1)L_n(x)$。
（1）证明：$(x^2 - 1)L_n'(x) = nxL_n(x) - nL_{n-1}(x)\ (n \geq 1)$。
（2）证明：$\int_{-1}^{1}(1 - x^2)L_i'(x)L_j'(x)\mathrm{d}x = \frac{2i(i+1)}{2i+1}\delta_{ij}\ (\forall i,j \geq 1)$。
（3）对于 $n \geq 1$，记 $s_j\ (1 \leq j \leq n)$ 是区间 $[-1,1]$ 上 $n$ 个高斯积分点，$w_j$ 是 $s_j$ 对应的权重。定义矩阵 $A = \left(L_j'(s_i)\right)_{n \times n}$，$W = \operatorname{diag}((1 - s_1^2)w_1,(1 - s_2^2)w_2,\cdots,(1 - s_n^2)w_n)$。证明：$B = A^{\mathrm{T}}WA$ 是一个对角矩阵。

指标约定：本书取 $A_{ij}=L'_j(s_i)$，即行对应节点、列对应多项式，与 $A^{\mathrm T}WA$ 的写法一致。若改用转置约定 $\widetilde A_{ij}=L'_i(s_j)$，相应的乘积应写成 $\widetilde A W\widetilde A^{\mathrm T}$。

# 解答

（1）将已知关系 $L'_{n-1}=xL'_n-nL_n$ 乘以 $x$，再减去 $L'_n=xL'_{n-1}+nL_{n-1}$，即得
\[
(x^2-1)L'_n=n(xL_n-L_{n-1}).
\]
$n=1$ 的边界情形也可直接验证。

（2）对上式求导并再次用已知微分关系，得 Legendre 方程
\[
\bigl((x^2-1)L'_n\bigr)'=n(n+1)L_n.
\]
分部积分，利用端点处 $1-x^2=0$ 及正交性，得到
\[
\int_{-1}^1(1-x^2)L'_iL'_j\,\mathrm dx
=i(i+1)\int_{-1}^1L_iL_j\,\mathrm dx
=\frac{2i(i+1)}{2i+1}\delta_{ij}.
\]
（3）若求积对两个基函数的乘积精确，连续正交就会传递到离散 Gram 矩阵。按 $A_{ji}=L'_i(s_j)$，有
\[
B_{ik}=\sum_{j=1}^nw_j(1-s_j^2)L'_i(s_j)L'_k(s_j).
\]
若 $i\ne k$，被积多项式的次数为 $i+k\le2n-1$，$n$ 点 Gauss 求积精确。故 $B_{ik}$ 等于（2）中的积分，即为零，$B$ 为对角阵。无需对次数为 $2n$ 的 $(n,n)$ 项误用求积精确性。
