# 题目

设 $S : r = (x,y,h(x,y))$ 为三维欧氏空间中的光滑曲面，$h(x,y)$ 是关于 $x,y$ 的光滑函数。

（1）求 $S$ 的平均曲率的表达式。

（2）设 $S$ 为极小曲面，当 $h(x,y) = f(x) + g(y)$ 时，求 $h(x,y)$ 的表达式，其中函数 $f,g$ 均为光滑函数。

# 解答

（1）取向上的单位法向 $\nu=(-h_x,-h_y,1)/\sqrt{1+h_x^2+h_y^2}$。由平均曲率是形算子迹的一半，
\[
H=\frac{(1+h_y^2)h_{xx}-2h_xh_yh_{xy}+(1+h_x^2)h_{yy}}
{2(1+h_x^2+h_y^2)^{3/2}}.
\]
改取反向法向时整体变号。

（2）可分离形式使混合导数消失，再除以 $(1+f'^{\,2})(1+g'^{\,2})$，便把两个变量分开。代入 $h=f(x)+g(y)$，极小曲面方程成为
\[
\frac{f''(x)}{1+f'(x)^2}=-\frac{g''(y)}{1+g'(y)^2}=c,
\]
因为等式两端分别只依赖于 $x,y$，故为常数。$c=0$ 时得到全部平面 $h=ax+by+d$；$c\ne0$ 时积分得到
\[
h(x,y)=\frac1c\log\left|\frac{\cos(cy+b)}{\cos(cx+a)}\right|+d,
\]
其中 $a,b,d$ 为常数，定义域取在两个余弦均不为零的矩形内。反过来这些函数直接满足极小曲面方程。若要求 $h$ 在整个 $\mathbb R^2$ 上光滑，则 $c\ne0$ 的情形不可能，因而只有平面。

# 评注

非平面分支是 Scherk 平移极小曲面，其对数余弦形式来自 $\arctan f'$ 与 $\arctan g'$ 的线性变化。它只能在避开余弦零点的区域内作为光滑图像；若定义域是整个平面，只有平面解。平均曲率及面积变分见[方法卷：曲面的局部几何](#app:geometry-surface)。
