# 题目

设 $\left\{f_{n}(x)\right\}_{n\geq 1}$ 是 $\mathbb{R}$ 上可测函数列，$f_{n}^{2},f^{2}\in\mathcal{L}(\mathbb{R})(\forall n\geq 1)$，
且对 $\mathcal{L}$-a.e. $x\in\mathbb{R}$ 有 $\lim_{n\to\infty}f_{n}(x)=f(x)$。若
\[
\lim_{n\to\infty}\int_{\mathbb{R}}\left|f_{n}(x)\right|^{2}\mathrm{d}m=\int_{\mathbb{R}}\left|f(x)\right|^{2}\mathrm{d}m,
\]
则
\[
\lim_{n\to\infty}\int_{\mathbb{R}}\left|f_{n}(x)-f(x)\right|^{2}\mathrm{d}m=0.
\]

# 解答

这是[第九届 $L^2$ 收敛题](#pr:fin09-hi:9)在 $E=\mathbb R$ 上的情形；该题的证明并未使用测度有限。为看清所需的唯一估计，记 $L=\|f\|_2^2$。Fatou 引理给出
\[
\liminf_n\|f_n+f\|_2^2\geq4L,
\]
而平行四边形恒等式给出
\[
\|f_n-f\|_2^2=2\|f_n\|_2^2+2L-\|f_n+f\|_2^2.
\]
题设使右端的上极限不超过 $4L-4L=0$，故所求极限为零。

# 评注

几乎处处收敛提供和的范数下界，范数收敛提供总能量上界；两者合在一起才排除了向远处移动或集中成尖峰的能量。系统说明见[方法卷：Hilbert 空间的收敛](#app:integration-hilbert)。
