# 题目

在空间直角坐标系中，设 $S$ 为椭圆柱面 $x^{2}+2y^{2}=1$，$\sigma$ 是空间中的平面，它与 $S$ 的交集为一个圆。求所有这样平面 $\sigma$ 的法向量。

# 解答

圆是平面内各方向伸缩比例相同的椭圆，因此应比较截线参数中的两个振幅向量。若平面平行于 $z$ 轴，交集只可能是直母线或为空，不可能是圆，故所求平面可写成 $z=\alpha x+\beta y+\gamma$。交线参数式为
\[
r(\theta)=(0,0,\gamma)+u\cos\theta+v\sin\theta,
\quad u=(1,0,\alpha),\quad v=\frac1{\sqrt2}(0,1,\beta).
\]
它是圆当且仅当 $u\cdot v=0$ 且 $|u|=|v|$，即
\[
\alpha\beta=0,\qquad 1+\alpha^2=\frac{1+\beta^2}{2}.
\]
因此 $\alpha=0,\beta=\pm1$。反过来，这两种情形的 $u,v$ 确实正交且均长为 $1$。全部法向量为 $(0,1,1)$ 或 $(0,-1,1)$ 的非零倍数。

# 评注

对 $x^2/a^2+y^2/b^2=1$（$a>b>0$），同样得到圆截平面
\[
z=\pm\frac{\sqrt{a^2-b^2}}{b}y+\gamma.
\]
斜截面沿短轴方向增加空间长度，使两个振幅向量等长。这正是“限制映射的 Gram 矩阵为单位阵的正倍数”这一判据，见[方法卷：仿射变换与度量](#app:geometry-affine)。
