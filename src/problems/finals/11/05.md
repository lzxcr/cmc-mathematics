# 题目

考虑单叶双曲面 $S: x^{2}-y^{2}+z^{2}=1$。

（1）证明：$S$ 上同一族直母线中任意两条不同的直母线是异面直线；

（2）设 $S$ 上同一族直母线中的两条直母线分别经过 $M_{1}(1,1,1)$ 与 $M_{2}(2,2,1)$ 两点，求这两条直母线的公垂线方程以及这两条直母线之间的距离。

# 解答

（1）以腰圆上的点标记一族直母线：
\[
L_\theta(t)=(\cos\theta-t\sin\theta,\ t,\ \sin\theta+t\cos\theta),
\qquad\theta\in\mathbb R/(2\pi\mathbb Z).
\]
直接代入即知它们都在 $S$ 上；另一族由 $y\mapsto-y$ 得到。若两条母线相交，交点的 $y$ 坐标使二者参数 $t$ 相同，而
\[
x+iz=e^{i\theta}(1+it)
\]
又迫使它们的 $\theta$ 相同。因此不同母线不相交。其方向向量 $(-\sin\theta,1,\cos\theta)$ 的第二分量都是 $1$，只有相同 $\theta$ 才可能平行。故同族不同母线均异面。

（2）两点已经同在另一族的直线 $x=y,z=1$ 上，因此题目中两条不同母线来自上述一族，分别为
\[
L_1=(1,1,1)+s(0,1,1),\qquad L_2=(2,2,1)+t(3,5,4).
\]
公垂线方向为 $(0,1,1)\times(3,5,4)=(-1,3,-3)$。令两足点之差同时垂直于两母线，解得两足点
\[
P=(1,-3/19,-3/19),\qquad Q=(17/19,3/19,-9/19).
\]
故公垂线为 $P+\tau(-1,3,-3)$，两母线距离为 $|P-Q|=2/\sqrt{19}$。

# 评注

参数化把“不相交”和“不平行”分开检查，避免把平行也误计为异面。第二问的公垂线计算则只需在两母线上找使距离平方最小的两点，其驻点条件就是连线同时垂直于两个方向。参见[方法卷：长度与正交投影](#app:geometry-length)。
