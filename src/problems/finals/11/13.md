# 题目

设 $S: r = r(u,v)$ 为 $\mathbb{R}^{3}$ 中的光滑曲面，其第一基本形式为
$(\mathrm{d}s)^{2} = E(\mathrm{d}u)^{2} + 2F \mathrm{d}u \mathrm{d}v + G(\mathrm{d}v)^{2}$，
其中 $(u,v)$ 为曲面 $S$ 的参数
\[
r_{u}=\frac{\partial r}{\partial u},\quad r_{v}=\frac{\partial r}{\partial v},\quad E=r_{u}\cdot r_{u},\quad F=r_{u}\cdot r_{v},\quad G=r_{v}\cdot r_{v}.
\]
证明：

（1）在每一点的某个邻域内存在新的参数 $(u_{1}, v_{1})$，使得 $S$ 的第一基本形式为 $(\mathrm{d}s)^{2}=h(u_{1}, v_{1})\left[\left(\mathrm{d}u_{1}\right)^{2}+\left(\mathrm{d}v_{1}\right)^{2}\right]$，其中 $h>0$ 为光滑函数。

（2）如果曲面 $S$ 的第一基本形式满足
$(\mathrm{d}s)^{2}=h(u, v)\left[\left(\mathrm{d}u\right)^{2}+\left(\mathrm{d}v\right)^{2}\right]$，
则其高斯曲率 $K$ 可以表示为 $K=-\frac{1}{2h}\Delta\log h$，其中 $h>0$ 为光滑函数，$\Delta=\frac{\partial^{2}}{\partial u^{2}}+\frac{\partial^{2}}{\partial v^{2}}$ 表示拉普拉斯算子。

# 解答

（1）等温坐标的存在性是局部结论，可由调和函数及其共轭构造。记曲面度量为 $g$。先在所考察点附近取一个满足 $\Delta_g u_1=0$ 且 $\mathrm du_1\ne0$ 的实函数。这样的函数由局部椭圆方程理论得到：在使中心处 $g_{ij}=\delta_{ij}$ 的坐标中，在小圆盘上解以第一坐标为边值的 Dirichlet 问题；缩放到单位圆盘后，系数趋于欧氏度量，椭圆内部估计保证解的中心梯度趋于 $(1,0)$。

在定向的小邻域内，调和性等价于 $\mathrm d(*\mathrm du_1)=0$，这里 $*$ 把余切平面中的一形式按度量正向旋转 $90^\circ$，因此保持长度并给出正交的一形式。Poincaré 引理给出 $v_1$ 使 $\mathrm dv_1=*\mathrm du_1$。于是两个微分正交、等长，且
\[
\mathrm du_1\wedge\mathrm dv_1=|\mathrm du_1|_g^2\,\mathrm dV_g\ne0.
\]
逆函数定理表明 $(u_1,v_1)$ 是局部坐标，度量遂为 $h(\mathrm du_1^2+\mathrm dv_1^2)$，其中 $h=|\mathrm du_1|_g^{-2}>0$。

（2）共形因子只改变长度尺度，所以选取与该尺度相适应的正交标架，曲率计算会化为一个 Laplacian。写 $h=e^{2\lambda}$，取正交余标架 $\omega_1=e^\lambda\mathrm du$、$\omega_2=e^\lambda\mathrm dv$。其联络形式为 $\eta=\lambda_v\mathrm du-\lambda_u\mathrm dv$，满足 $\mathrm d\omega_1=-\eta\wedge\omega_2$、$\mathrm d\omega_2=\eta\wedge\omega_1$。由曲率结构方程，
\[
K\omega_1\wedge\omega_2=\mathrm d\eta=-\Delta\lambda\,\mathrm du\wedge\mathrm dv,
\]
故 $K=-e^{-2\lambda}\Delta\lambda=-\frac1{2h}\Delta\log h$。

# 评注

关键的二维特性是：调和函数的微分旋转 $90^\circ$ 后仍是闭形式，因而局部有共轭函数。构造非临界调和函数仍须使用局部椭圆方程理论，不能只由逆函数定理得到。曲率公式进一步说明，这类坐标中 $K=0$ 等价于 $\log h$ 调和；曲面度量的基本语言见[方法卷：曲面的局部几何](#app:geometry-surface)。
