# 题目

在空间直角坐标系中设旋转抛物面 $\Gamma$ 的方程为 $z=\frac{1}{2}\left(x^{2}+y^{2}\right)$。设 $P$ 为空间中的平面，它交抛物面 $\Gamma$ 于交线 $C$。问：$C$ 是何种类型的曲线？证明你的结论。

# 解答

按平面是否平行于轴分类。若平面平行于 $z$ 轴，旋转坐标后可写为 $x=c$，交线 $z=(c^2+y^2)/2$ 是抛物线。

否则平面写为 $z=ax+by+c$。投影到 $xy$ 平面后，交集满足
\[
(x-a)^2+(y-b)^2=a^2+b^2+2c=:R^2.
\]
当 $R^2>0$ 时，空间交线是圆周经单射仿射映射 $(x,y)\mapsto(x,y,ax+by+c)$ 的像，故为椭圆（$a=b=0$ 时为圆）。当 $R^2=0$ 时交集退化为一点；当 $R^2<0$ 时为空集。因此非退化交线只有抛物线或椭圆两类。

# 评注

投影图形为圆，并不意味着空间截线也是圆：斜平面中的长度还含高度方向的贡献。本题非水平截面是椭圆，只有水平截面为圆；所用度量判据与[第七届圆截线题](#pr:fin07-hi:5)相同。
