# 题目

在空间直角坐标系中，椭球面 $S$ 和 $T$ 的方程为

\[
S:\; x^2+2y^2+3z^2=4,\qquad T:\; x^2+2y^2+3z^2=1.
\]

设直线 $L$ 交椭球面 $S$ 于 $A$ 和 $B$，交椭球面 $T$ 于 $C$ 和 $D$。证明：线段 $AB$ 的中点和线段 $CD$ 的中点重合；线段 $AC$ 和线段 $DB$ 的长度相等。

# 解答

记 $Q(x,y,z)=x^2+2y^2+3z^2$。将直线参数化为 $p+tv$，$v\ne0$，配方得到
\[
Q(p+tv)=a(t-t_0)^2+c,\qquad a=Q(v)>0.
\]
两个椭球面的交点参数分别由 $a(t-t_0)^2+c=4$ 与 $a(t-t_0)^2+c=1$ 给出，因此两对交点均关于 $t_0$ 对称，弦中点都是 $p+t_0v$。

关于此公共中点的中心对称将 $A$ 送到 $B$、$C$ 送到 $D$，故将线段 $AC$ 送到 $BD$，从而 $|AC|=|DB|$。

# 评注

同一正定二次型的不同等值椭球面，被任意直线截出的弦均有相同中点。配方只在一维参数上进行，不要求直线经过椭球中心。

公共中点是直线上使该二次型最小的点，因而与所取等值面无关；见[方法卷：二次型与极化](#app:geometry-quadric)。
