# 题目

非退化二次曲面 $\Sigma$ 经过以下九点：
\[
\begin{gathered}
A=(1,0,0),\quad B=(1,1,2),\quad C=(1,-1,-2),\\
D=(3,0,0),\quad E=(3,1,2),\quad F=(3,-2,-4),\\
G=(0,1,4),\quad H=(3,-1,-2),\quad I=(5,2\sqrt2,8).
\end{gathered}
\]
判断 $\Sigma$ 的类型。

# 解答

$A,B,C$ 共线，$D,E,F$ 共线，而且这两条直线平行且不同。二次多项式限制在一条直线上仍至多是二次多项式；它在三个不同点为零，就在整条直线上为零。因此 $\Sigma$ 含有两条不同的平行直线。

非退化实二次曲面中，含有直线的只有单叶双曲面与双曲抛物面。双曲抛物面可经可逆仿射变换写成 $z=xy$；其直线恰分为
\[
x=c,\ z=cy
\qquad\text{或}\qquad
y=c,\ z=cx.
\]
同族的不同直线不平行，异族的直线相交。因此双曲抛物面不含两条不同的平行直线。

故
\[
\boxed{\Sigma\text{ 是单叶双曲面。}}
\]

# 评注

这里“非退化”排除圆锥、柱面及平面并等情形。前六个点所提供的两条平行母线已决定曲面类型；其余点进一步限制方程。识别二次曲面中的直线，核心是把方程限制到直线上，见[方法卷：二次曲面的极化](#app:geometry-quadric)。
